# コンテンツ機能

Phase 6で端末内の動画、音声、写真を選択して再生する。テレビ・ラジオの描画部分と操作ボタンから開ける。写真は8秒ごとに自動表示でき、前後移動と停止が可能。

外部動画/音楽サービスへの接続、利用者写真のアップロード、永続保管は実装しない。選択ファイルをBlob URLで表示し、置換・閉じる操作で解放する。最大30件。画像15MB、音声50MB、動画150MB。MIMEの検証は操作補助であり、ファイル形式の完全な安全性保証ではない。再生はブラウザのメディア機能を使用。

自動再生を開始しない。非表示とネイティブ中断で再生を停止する。権利を持つファイルのみ利用する。昭和映像や市販楽曲の配布素材は未提供であり、同梱しない。

季節は端末の月に連動し、春の花、夏の草、秋の葉、冬の雪を数本の線で表現する。

## 同梱デモ素材

`apps/web/public/samples` に自作SVGの春・夏・冬、Canvasで描画した線画列車のWebM、数式で合成した小さなチャイムWAVを同梱。商用楽曲・他者の動画・本人の写真は含まない。`scripts/generate-samples.ts` で再生成できる。デモ素材は利用者の再生操作で開始し、自動再生しない。

## 天候データ

天候APIと地域検索はOpen-Meteoの公開APIを非商用デモに利用。現在地を選択したときは端末から取得した位置を0.1度に丸めた座標、地域検索時は入力した地域名を送信する。初期設定はOFFで自動測位しない。結果はメモリ内のみ。IPアドレスは通信先に伝わる。商用公開前にAPIライセンス・料金・可用性を再評価し、必要な契約を決める。ブラウザのCSPは天候・地名検索の送信先のみ追加する。
