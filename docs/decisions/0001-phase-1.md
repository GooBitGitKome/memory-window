# ADR 0001: Phase 1のローカル実装

Status: Proposed / developer review pending

ユーザーが新規作成を指示。SRS指定のReact + TypeScriptを使い、npm workspacesとViteで静的ビルドする。SVGで線画を作り、画像生成や外部CDNの依存を避ける。

固定挨拶はローカル日本語音声のSpeechSynthesisを利用。音源を同梱する方法より初期アセットが少ない一方、端末に音声がないと再生できない。文字フォールバックは用意するが、実機受け入れは未完了。

Supabase、Stripe、OpenAI、Cloudflare本番構成は実装しない。BYOK、権限、同意、利用制限は独立したADRとレビューを経て確定する。
