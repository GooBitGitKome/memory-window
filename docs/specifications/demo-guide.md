# デモ提示手順

`npm run demo` → http://localhost:4174 。すべての外部サービス操作は模擬。実キー・実音声の外部送信・実課金は行わない。

| 場面 | 操作 | 確認すること |
|---|---|---|
| 静かな暮らし | 窓を眺める、2回タップ、操作設定 | 白黒・余白、時刻と季節、手振りと固定挨拶、1回操作 |
| 会話 | Premium役を選び、窓で会話開始、定型のお話 | 聞く・話す動作、文字応答、いつでも終了 |
| 無料と有料 | 無料役で開始→設定で模擬申込→デモ接続登録 | サーバー側の制限、模擬解約、利用時間 |
| 本人のお願い | 電球の話→候補→非公開保存 | 会話全文が保存されず候補だけ残る |
| 支援者 | 本人の招待コード→支援者役で受ける→本人役で同意共有 | 招待だけでは非公開のお願いが見えず、同意済み項目だけ見える |
| 同意の撤回 | 本人役で撤回→支援者へ切替 | お願いが表示されなくなる。訂正で再度非公開、削除可能 |
| 権限外 | 権限のない支援者役へ切替 | 共有されたお願いが見えない |
| コンテンツ | テレビ・ラジオ・写真→デモ素材表示→再生 | 自作線画映像、静かな音、季節写真、閉じると停止 |

設定の「デモの全データを初期化」で最初から繰り返せる。デモサーバー終了でもデータは消える。

PWAとAndroid/iOSプロジェクトも生成済み。模擬デモはストア配布しない。実接続・ネイティブ実機・公開・費用制御の検証と重要箇所の開発者レビューを終えるまで、全フェーズの製品完成とは報告しない。

## 大きな窓と天候

通常画面の窓を拡大。右上「全画面」から出入りできる。「外の天候」で雨・雪などの模擬天候を選ぶと室内の窓だけが変化する。現在地ボタンは位置情報の許可を求め、地域検索では検索語をOpen-Meteoへ送る。取得失敗時や位置情報拒否時は模擬天候または天候連動OFFを利用する。
