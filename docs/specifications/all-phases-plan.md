# 全フェーズ実施計画

Scope: Phase 0–7。全フェーズ実施の指示で作業範囲を拡張。重要な設計承認・開発者レビュー・本番許可を省略するものではない。

## 実装前レポート

現在: Phase 1のReact/TypeScript/SVG、core、単体テスト、npm workspaces。バックエンド・認証・データベース・決済・AI通信・本番構成なし。

再利用: WindowScene、時刻・ノック・状態ルール、ライフサイクル制御。新規: セッション管理、Supabaseアダプター、権限・同意ルール、管理画面、課金アダプター、モバイル、PWA、メディア。

影響: apps/web、packages/core、依存/CI。後続でsupabase/functions・migrations、api-contractsを追加。

リスク: BYOK秘密情報、費用上限、RLS/IDOR、Webhook順序、同意撤回、音声端末差、ストア課金規約、コンテンツ権利。

## 順序と受け入れ条件

| Phase | 作業 | 完了の証拠 |
|---|---|---|
| 0 | 現状/差分/ADR | 実装前報告・設計レビュー |
| 1 | 線画・ノック・挨拶 | 単体/E2E/タッチ/音声/開発者レビュー |
| 2 | Realtime/WebRTC、BYOK、利用制限 | 実音声、割り込み、切断、復旧、漏洩/権限境界、費用制限 |
| 3 | 認証、管理UI、RLS、公開 | 複数利用者の隔離、権限テスト、限定公開許可、プライバシー方針 |
| 4 | Stripe、Webhook、Premium | テスト決済、重複/順序/失敗/解約、権限検証、開発者レビュー |
| 5 | Capacitor iOS/Android | ネイティブビルド、マイク、復帰、長時間実機、配布レビュー |
| 6 | テレビ/ラジオ/写真/季節 | 操作・停止・失敗処理・権利確認 |
| 7 | 生活ニーズ候補/同意/共有 | 拒否/撤回/訂正/削除/支援者権限、本人同意のレビュー |

認証基盤をPhase 2に先行させ、デモ実装の承認範囲で全フェーズを実装した。

公開用アカウント・支払い・資格情報の準備、本番公開、ストア登録は実施許可と外部環境が必要。未提供の環境をモックの成功で代替しない。

## デモ実装到達点（2026-10-10）

今回のユーザー指示により、全フェーズをデモ提示まで進める設計・実装が承認された。重要箇所の最終レビューと本番公開承認は別途必要。
