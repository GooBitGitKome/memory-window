# Phase 1 security and privacy

ランタイムに外部API、分析、Cookie、永続ストレージ、マイク、会話ログ、キー、ユーザーデータは使用しない。音声合成はlocalServiceの日本語音声だけを選ぶ。設定は画面内のメモリで保持する。

npmインストールは公開パッケージレジストリに接続する。ロックファイルで依存バージョンを記録する。

後続段階では認証・RLS・BYOK暗号化・課金権限・技術ログの保存期間を開発者がレビューする。家族への会話共有は実装しない。

## 後続フェーズ実装後の適用範囲

上記はPhase 1単独の記録。現在の実接続版は明示操作による録音、Supabase認証、暗号化キー、Stripeテスト、最小限の技術ログと同意済み項目を扱う。会話全文・音声を永続保存せず、家族に通常会話を提供しない。実接続の権限・秘密情報・運用設定は [接続仕様](../operations/connected-services.md) を確認する。ローカルデモは実キーを受け付けず外部AIへ送信しない。開発者による最終セキュリティ監査は未完了。
